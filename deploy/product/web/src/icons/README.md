# Chain and token icons

From [web3icons](https://github.com/0xa3k5/web3icons) (`@web3icons/core` 4.0.56), MIT-licensed (see
[LICENCE](LICENCE)), committed here so the page serves them itself (its CSP allows images only from
its own origin): `ethereum.svg` and `usdc.svg` from `dist/svgs/*/background/`, and `base.svg` from
`dist/svgs/networks/branded/` (Base's blue square, its viewBox cropped to the mark). `pha-token.svg`
is PHA's "P" mark from the background variant of `pha.svg`, in Phala's lime on black and scaled to
65%, so that it reads as a circle, like the other token marks, where the page rounds it as a token.
Phala Pay's own logo is not here: see [brand/](../../brand/README.md).

`github.svg` is GitHub's mark, `mark-github-16.svg` from [Primer Octicons](https://github.com/primer/octicons),
MIT-licensed (see [LICENCE-octicons](LICENCE-octicons)); it links to the repository, as GitHub's
logo guidelines allow.
